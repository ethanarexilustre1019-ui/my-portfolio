# Bespoke 3D UI & Tactical HUD Skill

## Visual Language
- **Frame Geometry**: Use angled tactical cuts (`clip-path: polygon(...)`) with corner reticles and subtle scanline/grid textures rather than generic rounded cards.
- **Kinetic Feedback**: Pair hover states with emerald bio-electric border illumination (`#00E676`), subtle coordinate telemetry readout shifts, and optional Web Audio synthesized tactile ticks (disabled by default).
- **3D Scene Integration**: Keep the right half of desktop viewports open in the Hero section so the 3D Emerald Vanguard Hero rig, floating obsidian monoliths, and One-For-All lightning arcs remain unobstructed while typography on the left stays high-contrast and legible.
